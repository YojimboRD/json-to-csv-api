# JSON to CSV Conversion API - Full Documentation

**Public URL:** https://boogeyman-unknowing-amenity.ngrok-free.dev

## Overview
A simple, fast REST API that converts JSON data to CSV format. Pay only $0.01 per request.

## Endpoints

### GET /
Returns API info and accepted formats.

### POST /convert
Converts JSON to CSV.

### GET /earnings
View usage stats and earnings.
